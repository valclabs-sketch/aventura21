# Aventura 21

Videojuego infantil para acompañar la creación de hábitos de estudio y autocuidado durante 21 días consecutivos, descansando los domingos.

## Jugar

La versión pública se encuentra en:

**https://valclabs-sketch.github.io/aventura21/**

## Desarrollo local

```bash
npm install
npm run dev
```

El avance de cada jugador se guarda únicamente en su dispositivo.
